# Maths Vault 1 - Website

This repo builds [math-vault-1](https://github.com/) (my Obsidian notes for Functions and Introductory Calculus) into a browsable website using [Quartz](https://quartz.jzhao.xyz/), and deploys it to GitHub Pages automatically on every push.


## Local preview

```
npm install
npx quartz build --serve
```
then open http://localhost:8080.
